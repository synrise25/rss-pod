# Security policy

Please do not open a public issue for suspected vulnerabilities or accidental
credential exposure. Use GitHub's private vulnerability reporting for this
repository when available.

When reporting a problem, include the affected version, deployment topology,
reproduction steps, and impact. Remove credentials, private feed content,
internal hostnames, and generated podcast material from logs before sharing.

Only the public player listener is intended for internet exposure. The
management listener must remain loopback-only and must not be published by
Docker or a reverse proxy.
